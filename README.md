# Retur Marketplace Pro

Aplikasi Android untuk pencatatan paket retur marketplace, scan barcode/QR, pencocokan database pesanan Pixel, impor Excel/CSV, riwayat, dan ekspor laporan.

## Build APK

Setiap push ke branch `main` akan menjalankan GitHub Actions untuk membangun APK debug. Buka tab **Actions**, pilih workflow **Build Android APK**, lalu unduh artefak `Retur-Marketplace-Pro-debug-apk` setelah proses berhasil.

Data aplikasi disimpan secara lokal pada perangkat. Ekspor/cadangkan data secara berkala agar aman.
